# 16-bit CUDA Inference (cuda16) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** a second CUDA backend, `cuda16` (engine `pc/cuda16`), whose residual trunk runs on the tensor cores with 16-bit operands and fp32 accumulation, batch-independent by construction, beside an unchanged `cuda`.

**Architecture:** `src/cuda/fp16/` holds the tensor-core implicit-GEMM convolution (`mma.sync.m16n8k16`, `cp.async`, `ldmatrix`, NHWC 16-bit activations, fp32 epilogue), the 16-bit network (weights converted once per upload; heads on the `cuda` backend's fp32 kernels), a runner with the `cuda` runner's structure, and probes. `include/azgo/cuda16.hpp` is the plain C++ interface. No file in `src/cuda/` (non-recursive) changes, so the `cuda` kernel hash and fingerprint do not.

**Spec:** docs/superpowers/specs/2026-10-24-cuda-fp16-design.md

**Author:** Mark Castelluccio, with planning assistance from Claude (Anthropic).

## Global Constraints

- **`cuda` and every non-CUDA build byte-identical.** Checked by an identity run against `main` (naive and BLAS builds on the PC, BLAS on the Studio) and by comparing `selfplay --fingerprint --backend cuda` between `main` and the branch.
- **The live run is untouched.** On the PC only `~/f16-scratch` (deleted at the end); GPU tests ≤ 60 s each, a few minutes per session; the strength check ~1 hour at `nice` with fewer workers. Checkpoints and SGFs are copied read-only from `runs/`.
- **Determinism by construction**, as `kernels.cuh` states it; `--fmad=false` and the other flags unchanged.
- **Privacy.** `git diff --cached | grep -nE '([0-9]{1,3}\.){3}[0-9]{1,3}|/Users/|/home/'` (plus the remote user's name) prints nothing before every commit.
- **Commits.** Author Mark; end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. No merge, no push.

### Task 2: the kernel and its bench
- [ ] `src/cuda/fp16/kernels16.cuh/.cu`: `conv16<T, NI>` (fp16 and bf16), the input conversion (`[B][P][A]` fp32 → NHWC 16-bit, 32-channel pad), the weight conversion, the channel-tile rule.
